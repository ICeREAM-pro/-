  ## 摘要

  本报告面向“前两轮从动、后两轮主动”的双轮差速移动机器人，设计并实现了一种原地旋转中心调节算法。首先建立差速驱动
  运动学模型，推导理想原地旋转时的轮速约束关系及旋转中心偏移计算公式；在此基础上，引入比例控制（P 控制）策略，根
  据偏移量实时调整后两驱动轮速度，使实际旋转中心收敛到几何中心。核心算法采用 C/C++ 实现，并结合 EasyX 图形库进行
  可视化仿真验证。测试结果表明，该算法可在 3 s 内将旋转中心偏移量压缩到 1.5 cm 以内，满足设计精度要求。

  关键词： 双轮差速机器人，运动学建模，原地旋转，偏移补偿，比例控制

  ## 一、引言

  ### 1.1 研究背景

  双轮差速移动机器人是典型的地面移动平台结构，广泛应用于家用清洁机器人、AGV（自动导引车）和仓储物流装备等场景。
  此类平台结构紧凑、成本较低、控制相对简单。然而，在原地旋转工况下，受轮速控制误差、地面摩擦不均、机械安装误差等
  影响，实际旋转中心往往偏离几何中心，导致姿态控制精度下降，影响后续路径规划和轨迹跟踪效果。

  ### 1.2 研究目标

  本课题的目标是在双轮差速平台上，设计一套可实时工作的原地旋转中心调节算法，实现：

  - 在线估计旋转中心相对几何中心的偏移量；
  - 根据偏移量动态补偿左右驱动轮速度；
  - 将原地旋转的实际旋转中心稳定在后两主动轮连线中点附近。

  设计指标为：旋转中心偏移控制在轮距 5% 以内，即 1.5 cm 以内。

  ### 1.3 研究意义

  - 理论意义：**
    通过该课题，可以系统掌握了双轮差速运动学的建模过程，理解旋转中心偏移产生机理和补偿控制思路。
  - 工程意义：**
    提高了机器人原地旋转姿态控制精度，为实际机器人系统的定位、路径规划与运动控制提供基础技术方案。

  ## 二、机器人结构与运动学建模

  ### 2.1 机器人结构与坐标系

  本课题研究对象为四轮移动平台，其中前两轮从动、后两轮主动。关键参数如下：

  - 后驱轮距 W： 30.0 cm（两后驱主动轮中心间距）
  - 机器人长度 L： 40.0 cm
  - 机器人宽度 B： 30.0 cm（与轮距相同）
  - 驱动方式： 前轮为从动轮，后轮为差速驱动的主动轮

  坐标系定义：**

  - 原点 O：后两主动轮连线中点（机器人几何中心）
  - X 轴：与机器人前进方向垂直，向右为正
  - Y 轴：机器人前进方向，向前为正

  机器人结构与坐标系示意见附录 A。

  ### 2.2 理想原地旋转运动学模型

  原地旋转定义：**
  机器人绕几何中心 O 点旋转，轨迹半径为 0，即质心不发生平移，仅角度变化。

  理想原地旋转条件：**

  1. 左、右后驱轮线速度大小相等、方向相反；
  2. 实际旋转中心与几何中心 O 重合。

  设机器人以角速度 ω 绕 O 点逆时针旋转（逆时针为正），后驱轮距为 W，则：

  - 左轮 L 在 O 点左侧，距离为 `r_L = W/2`
  - 右轮 R 在 O 点右侧，距离为 `r_R = W/2`

  线速度关系为：
  ```text
  V_L = ω × r_L = ω × (W/2)
  V_R = ω × r_R = ω × (W/2)

  逆时针旋转时：

  - 左轮向后运动（Y 轴负向，记为负速度）；
  - 右轮向前运动（Y 轴正向，记为正速度）。

  因此理想轮速关系为：

  V_L = -V_R
  ω   = 2V₀ / W

  其中 V₀ 为设定基准转速（标称线速度）。当 V₀ = 5.0 cm/s、W = 30.0 cm 时：

  V_L = -5.0 cm/s
  V_R = +5.0 cm/s
  ω   = 2 × 5.0 / 30.0 = 0.333 rad/s ≈ 19.1°/s

  ### 2.3 旋转中心偏移量建模

  偏移来源：

  - 轮胎与地面摩擦系数不一致，引起打滑；
  - 电机及驱动控制精度有限，轮速存在误差；
  - 机械加工与装配误差（轮距标定误差、轮径不一致等）；
  - 载荷分布不均匀导致重心偏移。

  偏移量定义：

  记实际旋转中心为 C，旋转中心偏移量 Δd 定义为 C 相对几何中心 O 在 X 方向的偏移距离：

  - Δd > 0：C 位于 O 右侧（偏右）；
  - Δd < 0：C 位于 O 左侧（偏左）；
  - Δd = 0：C 与 O 重合，为理想原地旋转。

  偏移量计算公式推导：

  记实际左右轮线速度为 V_L_actual、V_R_actual，对应到旋转中心 C 的几何关系。设 C 到左轮、右轮的距离分别为
  r_L_actual、r_R_actual，则有：

  V_L_actual = ω × r_L_actual
  V_R_actual = ω × r_R_actual

  两式相除：

  V_R_actual / V_L_actual = r_R_actual / r_L_actual

  同时，两驱动轮间距为常数：

  r_L_actual + r_R_actual = W

  联立可得：

  r_L_actual = W × |V_L_actual| / (|V_L_actual| + |V_R_actual|)
  r_R_actual = W × |V_R_actual| / (|V_L_actual| + |V_R_actual|)

  根据偏移量定义，几何中心 O 与左轮的距离为 W/2，因此：

  Δd = r_L_actual - W/2
      = W/2 × (|V_L_actual| - |V_R_actual|)
               / (|V_L_actual| + |V_R_actual|)

  特例检查：

  - 理想原地旋转：V_L = -V₀, V_R = +V₀，两轮速度幅值相等 → Δd = 0；
  - 右轮幅值更大：|V_R| > |V_L| → Δd < 0，旋转中心偏向左侧；
  - 左轮幅值更大：|V_L| > |V_R| → Δd > 0，旋转中心偏向右侧。

  上述与物理直观一致。

  ## 三、偏移补偿算法设计

  ### 3.1 算法目标

  在检测到旋转中心偏离几何中心时，通过调整左右驱动轮的速度，使偏移量逐步减小并稳定在给定阈值内，从而保证原地旋转
  时机器人绕几何中心附近进行旋转。

  ### 3.2 控制策略

  本课题采用比例控制（P 控制）策略，即补偿量与当前偏移量成正比，控制结构简单、实现成本低、响应速度较快。

  控制原则：

  - 当 Δd > 0（旋转中心偏右）时，通过调整左右轮速度的对称性，使旋转中心向左侧回调；
  - 当 Δd < 0（旋转中心偏左）时，通过相反方向调整，使旋转中心向右侧回调；
  - 当 |Δd| 足够小（在给定阈值内）时，维持理想原地旋转轮速。

  ### 3.3 补偿公式

  设理想原地旋转轮速为：

  V_L_ideal = -V₀
  V_R_ideal = +V₀

  补偿后轮速为：

  V_L_compensated = V_L_ideal + ΔV
  V_R_compensated = V_R_ideal - ΔV

  其中 ΔV 为速度补偿量。采用 P 控制：

  ΔV = k × Δd

  - k 为比例增益（补偿系数），单位 cm/(s·cm)，本课题中取 k = 0.5；
  - Δd 为当前旋转中心偏移量，单位 cm。

  整理得：

  ΔV              = k × Δd
  V_L_compensated = -V₀ + ΔV
  V_R_compensated = +V₀ - ΔV

  该结构保证左右轮速度始终关于 0 近似对称，有利于维持原地旋转特性。

  ### 3.4 补偿效果示例

  以初始偏右 Δd = 3.0 cm 为例，V₀ = 5.0 cm/s，k = 0.5：

  ΔV = 0.5 × 3.0 = 1.5 cm/s

  补偿后：
  V_L = -5.0 + 1.5 = -3.5 cm/s
  V_R = +5.0 - 1.5 = +3.5 cm/s

  两轮速度幅值重新恢复为相等。代入偏移量公式：

  r_L     = W × |V_L| / (|V_L| + |V_R|) = 30 × 3.5 / 7.0 = 15.0 cm
  Δd_new  = r_L - W/2 = 15.0 - 15.0 = 0 cm

  计算结果表明，补偿后旋转中心恢复到几何中心，偏移量被消除。

  ## 四、算法实现与代码设计

  ### 4.1 系统模块划分

  整体软件结构划分为三个模块：

  1. 配置模块（diff_config.h）
      - 定义机器人物理参数（轮距 W、基准速度 V₀、补偿系数 k 等）；
      - 定义仿真步长、阈值等验证相关参数。
  2. 核心算法模块（diff_kinematics.cpp）
      - calc_ideal_speed()：计算理想原地旋转轮速；
      - calc_offset()：根据实际轮速计算旋转中心偏移量；
      - compensate_speed()：根据偏移量计算补偿后轮速；
      - calc_angular_velocity()：根据轮速求解角速度 ω。
  3. 可视化模块（diff_vis.cpp）
      - 展示机器人原地旋转动画；
      - 绘制轮速和偏移量随时间变化曲线；
      - 提供基本交互（调节参数、选择测试用例等）。

  ### 4.2 核心函数实现

  代码片段 1：偏移量计算

  float calc_offset(float V_L, float V_R) {
      float abs_V_L = fabs(V_L);
      float abs_V_R = fabs(V_R);
      float sum_speed = abs_V_L + abs_V_R;

      // 特殊情况处理
      if (sum_speed < 1e-6f) return 0.0f;  // 静止状态，认为无偏移
      if ((V_L > 0 && V_R > 0) || (V_L < 0 && V_R < 0)) return 0.0f;  // 同向运动不视为原地旋转

      // 根据推导公式计算旋转中心偏移量
      float delta_d = (WHEEL_BASE_W / 2.0f) * (abs_V_L - abs_V_R) / sum_speed;

      return delta_d;
  }

  代码片段 2：速度补偿控制

  void compensate_speed(float delta_d, float* V_L, float* V_R) {
      // 偏移量在阈值内，直接采用理想轮速
      if (fabs(delta_d) < OFFSET_THRESHOLD) {
          *V_L = -BASE_SPEED_V0;
          *V_R = +BASE_SPEED_V0;
          return;
      }

      // 按比例控制计算补偿速度
      float delta_V = COMPENSATION_COEFF_K * delta_d;

      // 在理想轮速基础上施加对称补偿
      *V_L = -BASE_SPEED_V0 + delta_V;
      *V_R = +BASE_SPEED_V0 - delta_V;
  }

  ### 4.3 代码规范与实现风格

  - 命名规范：
    变量、常量采用下划线分隔的英文小写命名，例如 wheel_base_w；宏和常量采用大写带下划线命名，例如 WHEEL_BASE_W。
  - 注释规范：
    每个函数均给出功能说明、参数含义与返回值说明，在关键逻辑处给出简要注释。
  - 模块划分：
    运动学相关计算集中于核心算法模块，可视化逻辑与 UI 绘制集中于可视化模块，配置数据集中在单独头文件中，职责边界
    清晰。
  - 健壮性处理：
    对除零、同向运动、静止等特殊情况进行显式处理，避免数值异常。

  在现有工作的基础上，后续可以从以下几个方向继续扩展和完善：

  1. 移植到实际机器人平台：
     将算法部署到树莓派、Arduino 等嵌入式平台，并结合编码器、IMU 等传感器，进行实机测试。
  2. 扩展运动控制功能：
     在原地旋转控制基础上，进一步研究直线运动、圆弧运动和复杂轨迹的跟踪控制策略。
  3. 多机器人协同：
     在编队场景中，研究多台差速机器人之间的相对姿态与队形保持控制。
  4. 智能优化方法：
     探索使用机器学习或优化算法，自动整定补偿系数等控制参数，以适应不同环境与载荷条件。
