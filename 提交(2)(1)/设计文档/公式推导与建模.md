## 二、理想原地旋转运动学模型推导

### 2.1 理想原地旋转的定义

**原地旋转**：机器人绕几何中心O点旋转，旋转半径为0，即旋转中心coincide with几何中心。

**理想条件**：
1. 左主动轮和右主动轮速度大小相等、方向相反
2. 旋转中心精确位于后两轮连线的中点O
3. 前从动轮自由跟随旋转，不提供驱动力

### 2.2 理想轮速关系推导

#### 步骤1：建立运动学关系

设机器人以角速度 ω 绕几何中心O旋转（逆时针为正）。

对于左主动轮L（位于O点左侧，距离O点 W/2）：
- 左轮到旋转中心的距离：**r_L = W/2**
- 左轮线速度：**V_L = ω × r_L = ω × (W/2)**
- 方向：逆时针旋转时，左轮向后运动（负方向）

对于右主动轮R（位于O点右侧，距离O点 W/2）：
- 右轮到旋转中心的距离：**r_R = W/2**
- 右轮线速度：**V_R = ω × r_R = ω × (W/2)**
- 方向：逆时针旋转时，右轮向前运动（正方向）

#### 步骤2：推导速度关系

**结论1：速度大小相等、方向相反**

```
V_L = -ω × (W/2)   (左轮向后，负号表示方向)
V_R = +ω × (W/2)   (右轮向前，正号表示方向)

因此：V_L = -V_R
```

**结论2：角速度与轮速的关系**

从上式可得：
```
ω = (V_R - V_L) / W = 2V_R / W = -2V_L / W
```

特别地，当设定基准转速 V₀ = 5.0 cm/s 时：
```
V_L = -V₀ = -5.0 cm/s
V_R = +V₀ = +5.0 cm/s
ω = 2V₀ / W = 2 × 5.0 / 30.0 = 0.333 rad/s ≈ 19.1°/s
```

### 2.3 理想运动学模型总结

**理想原地旋转的核心公式：**

```
┌─────────────────────────────────────┐
│  V_L = -V_R                         │  (速度大小相等、方向相反)
│  ω = 2V₀ / W                        │  (角速度)
│  V_L = -V₀,  V_R = +V₀              │  (具体数值)
└─────────────────────────────────────┘
```

## 三、旋转中心偏移量计算模型

### 3.1 偏移产生的原因

实际运动中，由于以下因素会导致旋转中心偏移：
1. 轮子打滑**：地面摩擦力不均匀
2. 速度控制误差**：电机转速存在波动
3. 机械误差**：轮距测量不准确、轮子半径不一致
4. 负载不均**：机器人重心不在几何中心

这些因素导致**实际旋转中心偏离几何中心O点**。

### 3.2 偏移量定义

**偏移量 Δd**：实际旋转中心相对于几何中心O的X方向距离。

```
           Y轴
            ↑
            |
    左轮 ●--+--●--+--● 右轮
           O   Δd  C
         理想   偏移  实际
         中心        中心

规定：
- Δd > 0：实际旋转中心C在O点右侧（偏右）
- Δd < 0：实际旋转中心C在O点左侧（偏左）
- Δd = 0：实际旋转中心与几何中心重合（理想状态）
```

### 3.3 偏移量计算方法

#### 方法1：通过实际轮速反推

已知实际左右轮速度 V_L_actual 和 V_R_actual，可反推实际旋转中心位置。

**推导过程：**

设实际旋转中心C距离左轮距离为 r_L_actual，距离右轮距离为 r_R_actual。

由运动学关系：
```
V_L_actual = ω × r_L_actual
V_R_actual = ω × r_R_actual
```

两式相除：
```
V_R_actual / V_L_actual = r_R_actual / r_L_actual
```

又因为：
```
r_L_actual + r_R_actual = W  (左右轮距离之和恒为轮距W)
```

联立求解：
```
r_L_actual = W × |V_L_actual| / (|V_L_actual| + |V_R_actual|)
r_R_actual = W × |V_R_actual| / (|V_L_actual| + |V_R_actual|)
```

**偏移量计算：**
```
Δd = r_L_actual - W/2 = W/2 × (|V_L_actual| - |V_R_actual|) / (|V_L_actual| + |V_R_actual|)
```

**特例验证：**
- 理想状态：V_L = -V₀, V_R = +V₀ → Δd = 0 
- 右轮快：|V_R| > |V_L| → Δd < 0（偏左）
- 左轮快：|V_L| > |V_R| → Δd > 0（偏右）

#### 方法2：通过机器人边缘点轨迹对比（仿真验证用）

在可视化仿真中，可通过追踪机器人某个边缘点的实际轨迹与理想轨迹对比：

```
选取机器人前端中心点P（坐标：(0, L/2)）

理想旋转：P点绕O旋转，半径 r_ideal = L/2
实际旋转：P点绕C旋转，半径 r_actual = sqrt((L/2)² + Δd²)

经过时间t后：
理想位置：P_ideal = (r_ideal × sin(ωt), r_ideal × cos(ωt))
实际位置：P_actual = (Δd + r_actual × sin(ωt), r_actual × cos(ωt))

偏移量：Δd ≈ P_actual.x - P_ideal.x (当ωt较小时)
```

## 四、偏移补偿算法推导

### 4.1 补偿目标

**目标**：当检测到旋转中心偏移时，动态调整左右轮速度，使旋转中心回归几何中心O。

**补偿原则**：
- 偏右时（Δd > 0）：增加左轮速度、减小右轮速度，使旋转中心左移
- 偏左时（Δd < 0）：减小左轮速度、增加右轮速度，使旋转中心右移

### 4.2 补偿公式推导

#### 步骤1：建立补偿速度关系

设补偿速度为 ΔV**，补偿后的轮速为：
```
V_L_compensated = V_L_ideal + ΔV_L
V_R_compensated = V_R_ideal + ΔV_R
```

补偿要求：
1. 保持角速度不变**：ω = (V_R_compensated - V_L_compensated) / W = 常数
2. 使旋转中心回归O点**：调整速度差，使 r_L_actual → W/2

#### 步骤2：推导补偿量

采用**比例控制**策略（P控制）：
```
ΔV = k × Δd
```

其中：
- k 为补偿系数，单位：cm/(s·cm)，预设值 k = 0.5
- Δd 为偏移量，单位：cm

**补偿规则：**
```
当 Δd > 0（偏右）时：
    V_L_compensated = V_L_ideal + ΔV = -V₀ + k×Δd  (增加左轮速度)
    V_R_compensated = V_R_ideal - ΔV = +V₀ - k×Δd  (减小右轮速度)

当 Δd < 0（偏左）时：
    V_L_compensated = V_L_ideal + ΔV = -V₀ + k×Δd  (减小左轮速度，因为Δd<0)
    V_R_compensated = V_R_ideal - ΔV = +V₀ - k×Δd  (增加右轮速度，因为Δd<0)
```

**统一表达式：**
```
┌────────────────────────────────────────┐
│  ΔV = k × Δd                           │
│  V_L_compensated = -V₀ + ΔV            │
│  V_R_compensated = +V₀ - ΔV            │
└────────────────────────────────────────┘
```

### 4.3 补偿效果验证

#### 数值示例1：初始偏右 Δd = 3.0 cm

```
补偿速度：ΔV = 0.5 × 3.0 = 1.5 cm/s

补偿后轮速：
V_L = -5.0 + 1.5 = -3.5 cm/s  (左轮减速，绝对值减小)
V_R = +5.0 - 1.5 = +3.5 cm/s  (右轮减速)

验证旋转中心：
r_L = W × |V_L| / (|V_L| + |V_R|) = 30 × 3.5 / 7.0 = 15.0 cm
Δd_new = r_L - W/2 = 15.0 - 15.0 = 0 cm   偏移消除！
```

#### 数值示例2：初始偏左 Δd = -2.0 cm

```
补偿速度：ΔV = 0.5 × (-2.0) = -1.0 cm/s

补偿后轮速：
V_L = -5.0 + (-1.0) = -6.0 cm/s  (左轮加速，绝对值增大)
V_R = +5.0 - (-1.0) = +6.0 cm/s  (右轮加速)

验证旋转中心：
r_L = W × |V_L| / (|V_L| + |V_R|) = 30 × 6.0 / 12.0 = 15.0 cm
Δd_new = 15.0 - 15.0 = 0 cm   偏移消除！
```

### 4.4 补偿系数k的选择

**k值过大**：补偿过度，可能导致振荡
**k值过小**：补偿缓慢，收敛时间长

经验推荐：
```
k ∈ [0.3, 0.8] cm/(s·cm)
预设值：k = 0.5 cm/(s·cm)
```

## 五、核心公式总结

### 5.1 理想运动学公式

| 公式名称 | 数学表达式 | 说明 |
|---------|-----------|------|
| 理想轮速关系 | V_L = -V_R | 速度大小相等、方向相反 |
| 角速度公式 | ω = 2V₀ / W | V₀=5cm/s, W=30cm → ω=0.333rad/s |
| 具体轮速值 | V_L = -5.0 cm/s<br>V_R = +5.0 cm/s | 基准转速设定 |

### 5.2 偏移量计算公式

```
Δd = (W/2) × (|V_L| - |V_R|) / (|V_L| + |V_R|)
```

### 5.3 补偿控制公式

```
ΔV = k × Δd
V_L_compensated = -V₀ + ΔV
V_R_compensated = +V₀ - ΔV
```

### 5.4 完整控制流程

```
1. 获取当前实际轮速：V_L_actual, V_R_actual
2. 计算偏移量：Δd = (W/2) × (|V_L| - |V_R|) / (|V_L| + |V_R|)
3. 判断是否需要补偿：if |Δd| > 阈值(0.1cm)
4. 计算补偿速度：ΔV = k × Δd
5. 应用补偿：V_L = -V₀ + ΔV,  V_R = +V₀ - ΔV
6. 输出到电机控制
7. 返回步骤1，形成闭环控制
```
